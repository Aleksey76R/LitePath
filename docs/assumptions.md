# Принятые допущения

| № | Вопрос | Решение |
|---|--------|---------|
| 1 | Управление | Сигналы (speed_mps, steer_angle_deg) как структура данных; реальная подача на актуаторы не требуется. Адаптер в `sim_adapters/` для CARLA |
| 2 | Синхронизация | nearest timestamp, буфер 1 кадр, порог 50 мс → флаг `sync_quality=low` |
| 3 | Локализация | Ближайший узел графа + коррекция по визуальным ориентирам; `LowConfidence` при > 1.5 м; целевая ошибка ≤ 1.2 м; без EKF/PF |
| 4 | Датасет | Fine-tune на 200–300 кадрах + аугментации (+ опц. синтетика CARLA); обучение с нуля не проводится |
| 5 | Препятствия | Минимум — статика; динамика (пешеходы) — stretch goal |
| 6 | Успех сценария | ≤ 1 м до цели, без аварийных остановок, ≤ 1 перепланирование, скорость в конце ≤ 0.5 м/с; N ≥ 5 прогонов |
| 7 | Бенчмарки | Обязательно CPU-only; GPU/Jetson — опционально; критерии приёмки достижимы на CPU |
| 8 | Лидар | `.pcd` основной, `.bin` опц.; СК: x-вперёд, y-влево, z-вверх; метры |
| 9 | Квантование | INT8 через ONNX Runtime, калибровка на 100 кадрах train, падение mAP@0.5 ≤ 5%, иначе FP16 |
| 10 | Симулятор | CARLA в офлайн-режиме (PNG + PCD + JSON); онлайн-режим не обязателен |
| 11 | Детектор | Своя облегчённая архитектура (MobileNetV3-small + голова 4 класса, без P5) с предобученным backbone; baseline — YOLOv8-nano; fallback — pruned YOLOv8-nano |
| 12 | Границы оптимизации | Переписывание OpenCV/NumPy, INT4, переход на C++ — явно отклонены (антипаттерны) с обоснованием |
